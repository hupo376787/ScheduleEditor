# Changelog

All notable changes to this project are documented in this file.

## 1.0.0 - 2026-07-24

- Added interval schedules for every N seconds, minutes, and hours.
- Added daily, weekly, monthly, and custom five/six-field Cron schedules.
- Added per-mode visibility switches; daily, weekly, and monthly are visible by default.
- Added FluentScheduler-based in-process execution and overlap protection.
- Added JSON persistence through `IScheduleStore`, `JsonScheduleStore`, and `ScheduleManager`.
- Added built-in Simplified Chinese and English localization.
- Added complete and partial external JSON language-pack support.
- Added HotAvalonia development-time Hot Reload.
- Added bilingual documentation and a runnable Avalonia demo.
